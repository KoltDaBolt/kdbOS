# kdbOS
A personal hobby operating system built to explore how operating systems work under the hood.

## Recommended Development Environment
* **Linux:** (Developed in WSL running Ubuntu-22.04)

## Required Packages
To build and run kdbOS, you will need to install the following tools:

* `build-essential`
* `binutils`
* `nasm`
* `qemu-system`
* `grub-pc-bin`
* `grub-common`
* `xorriso`
* `vgabios`

> **IMPORTANT:** You must enable **Legacy Booting** in your BIOS. This will not boot under UEFI mode.
