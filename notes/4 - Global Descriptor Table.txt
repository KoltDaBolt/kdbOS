-=-=-=-=-= The Global Descriptor Table =-=-=-=-=-
Each entry in the GDT is 8 bytes long and has the following structure:

|00000000||0000||0000||00000000||00000000|00000000|00000000||00000000|00000000|
|__base__||_FL_||LMT_||_Access_||___________base___________||______limit______|

Limit: A 20-bit value, tells the maximum addressable unit, either in 1 byte units, or 4 KB pages.
Base: A 32-bit value containing the address where the segment begins
Access Byte: Present bit, descriptor privilege level field (takes two bits), descriptor type, executable bit, conforming bit, read/write bit, access bit
Flags Byte: Granularity flag, Size flag, long-mode code flag

-=-=-=-=-= Flat Mode Setup =-=-=-=-=-
If you do not wish to use segmentation, then you can setup your table as follows:

|-------+----------------------------+-------------------------|
|offset |   use                      |  content                |
|-------+----------------------------+-------------------------|
| 0x0   |   Null Descriptor          |  Base = 0               |
|       |                            |  Limit = 0x00           |
|       |                            |  Access Byte = 0x00     |
|       |                            |  Flags = 0x0            |
|-------+----------------------------+-------------------------|
| 0x08  |   Kernel Code Segment      |  Base = 0               |
|       |                            |  Limit = 0xFFFFF        |
|       |                            |  Access Byte = 0x9A     |
|       |                            |  Flags = 0xC            |
|-------+----------------------------+-------------------------|
| 0x10  |   Kernel Data Segment      |  Base = 0               |
|       |                            |  Limit = 0xFFFFF        |
|       |                            |  Access Byte = 0x92     |
|       |                            |  Flags = 0xC            |
|-------+----------------------------+-------------------------|
| 0x18  |   User Code Segment        |  Base = 0               |
|       |                            |  Limit = 0xFFFFF        |
|       |                            |  Access Byte = 0xFA     |
|       |                            |  Flags = 0xC            |
|-------+----------------------------+-------------------------|
| 0x20  |   User Data Segment        |  Base = 0               |
|       |                            |  Limit = 0xFFFFF        |
|       |                            |  Access Byte = 0xF2     |
|       |                            |  Flags = 0xC            |
|-------+----------------------------+-------------------------|
| 0x28  |   Task State Segment       |  Base = 0               |
|       |                            |  Limit = sizeof(TSS)-1  |
|       |                            |  Access Byte = 0x89     |
|       |                            |  Flags = 0x0            |
|-------+----------------------------+-------------------------|

-=-=-=-=-= Access Byte Values =-=-=-=-=-
00000000
||||||||
||||||||_A (Accessed Bit)
|||||||_RW (Readable / Writable Bit)
||||||_DC (Direction / Conforming Bit)
|||||_E (Executable Bit)
||||_S (Descriptor Type Bit)
||__DPL (Descriptor Privilege Level Field)
|_P (Present Bit)
Present Bit: Allows an entry to refer to a valid segment. Must be 1

P: Allows an entry to refer to a valid segment
DPL: Contains the CPU privilege level of the segment. 0 = highest privilege (kernel), 3 = lowest privilege (user applications)
S: If 0, bit defines a system segment. If 1, bit defines a code or data segment
E: If 0, bit defines a data segment. If 1, bit defines a code segment
DC: For data selectors: If 0 the segment grows up. If 1 the segment grows down
    For code selectors: If 0, the code can only be executed from the ring level set in DPL. If 1, code can be executed from an equal or lower privilege
RW: For code segments (readable bit): If 0, read access is not allowed. If 1, read access is allowed. Write access is never allowed for code segments
    For data segments (writable bit): If 0, write access is not allowed. If 1, write access is allowed. Read access is always allowed for data segments
A: The CPU will set this when the segment is accessed or unless set to 1 in advance.

-=-=-=-=-= Flags Byte Values =-=-=-=-=-
0000
||||_Reserved
|||_L (Long-Mode Code Flag)
||_DB (Size Flag)
|_G (Granularity Bit)

G: Indicates the size the limit value is scaled by. If 0, the limit is in 1 byte blocks. If 1, the limit is in 4 KB blocks
DB: If 0, descriptor defines 16-bit protected mode segment. If 1, descriptor defines 32-bit protected mode segment
L: If 1, descriptor defines 64-bit code segment. When set, DB should always be 0
